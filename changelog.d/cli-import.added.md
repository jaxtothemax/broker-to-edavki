- **Command line**: `taxreporter <exports...> --year 2026 --tax-number <number> --out <folder>` now reads Trading 212 history exports and Interactive Brokers Activity Flex Query statements and writes the Doh-KDVP and Doh-Div files for eDavki into the folder you name. It prints what it read, the estimated tax, and every finding grouped by how serious it is. It exits with an error code while anything still blocks the return, so scripts can rely on it. Payer details for dividends come from a small JSON file (`--payers`), since brokers do not export them. A PDF, an old Excel file, or text that is not UTF-8 is refused before any of its contents are read. A run takes at most 100 files, of 256 MiB together: a file past that is measured, never read, and the run writes nothing. `--json` prints the same report for other tools to read. It says what became of each return (written, withheld, or nothing to file), and the summary says so beside the estimate of a return that is not written, as the web app does: the figure may change once what stops the return is fixed. While a file is refused, both returns are withheld, since a file that was not read may hold the year's sales or payments.
